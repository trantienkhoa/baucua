❓ Hướng dẫn lên LIVE

  • OBS: Sources → + → Browser → dán link "OBS", khung 1080 × 1920, bật Control audio via OBS.
  • TikTok LIVE Studio: Thêm nguồn → Liên kết → dán link "LIVE Studio" (127.0.0.1). Không nhận thì dùng link mạng LAN. Vẫn không được: bấm 🪟 Cửa sổ riêng rồi chọn Chụp cửa sổ / Window Capture.
  • LIVE bằng điện thoại: điện thoại cùng Wi-Fi mở link "Điện thoại".
  • Windows hỏi tường lửa lần đầu: bấm Cho phép để điện thoại / LIVE Studio vào được link LAN.
  • Giọng MC hay nhất: mở trang điều khiển bằng Microsoft Edge.
