2. Đưa lên LIVE

Hướng dẫn từng phần mềm
  • OBS: Sources → + → Browser → dán link "OBS", 1080 × 1920, bật Control audio via OBS. Settings → Advanced: bật Browser Source Hardware Acceleration cho 3D mượt.
  • TikTok LIVE Studio: Thêm nguồn → Liên kết → dán link "LIVE Studio". Không nhận thì dán link mạng LAN. Vẫn không được: bấm Mở màn hình LIVE trong cửa sổ riêng rồi chọn Chụp cửa sổ / Window Capture → cửa sổ "Nation Rush".
  • LIVE bằng điện thoại: điện thoại cùng Wi-Fi mở link "Điện thoại", rồi dùng tính năng chia sẻ màn hình / Mobile gaming của TikTok.
  • Windows hỏi tường lửa lần đầu: bấm Cho phép để điện thoại / LIVE Studio vào được link LAN. Wi-Fi quán / văn phòng có thể chặn thiết bị thấy nhau — khi đó dùng điểm phát sóng của điện thoại.
