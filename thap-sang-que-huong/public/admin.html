2. Đưa lên LIVE

Hướng dẫn từng phần mềm
  • OBS: Sources → + → Browser → dán link "OBS", 1080 × 1920, bật Control audio via OBS.
  • TikTok LIVE Studio: Thêm nguồn → Liên kết → dán link "LIVE Studio" (127.0.0.1). Không nhận thì dán link mạng LAN. Vẫn không được: bấm Mở màn hình LIVE trong cửa sổ riêng rồi trong LIVE Studio chọn Chụp cửa sổ / Window Capture → chọn cửa sổ "Thắp Sáng Quê Hương".
  • LIVE bằng điện thoại: điện thoại cùng Wi-Fi mở link "Điện thoại", rồi dùng tính năng chiếu màn hình / livestream màn hình.
  • Windows hỏi tường lửa lần đầu chạy: bấm Cho phép (cả mạng riêng tư) để điện thoại / LIVE Studio vào được link LAN.

🚫 Bộ lọc từ

Mỗi từ cách nhau dấu phẩy hoặc xuống dòng. Bình luận có từ cấm sẽ không được tính, tên có từ cấm hiện là “Khách ẩn danh”. Link, số điện thoại, Zalo luôn bị chặn.
